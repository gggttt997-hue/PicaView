# PicaView

> 本地图片与漫画查看器。

PicaView 是一款基于 **Native Rust + Slint + WGPU** 构建的本地桌面工具，主要用于常规图片查看与本地漫画阅读。依托 **WGPU 28** 硬件加速与 VRAM Streaming 显存策略，在处理较高分辨率图像时能保持相对流畅的交互体验，满足日常使用需求。

---

## 🚀 快速开始

### 方式 A: Linux (Ubuntu/Debian/Fedora)
```bash
# 安装 Rust 与 系统依赖 (如果尚未安装)
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
sudo apt-get update && sudo apt-get install -y libfontconfig1-dev libxcb-shape0-dev libxcb-xfixes0-dev libxkbcommon-dev

# 克隆并运行开发版本
git clone https://github.com/MikeWu-GM/PicaView.git
cd PicaView
cargo run --release -- /path/to/your/image.jpg
```

### 方式 B: Windows (安装包与 PowerShell)
**普通用户：** 请在 Releases 页面下载最新的 `picaview-0.1.0-x86_64.msi` 安装包。它不仅会自动配置系统 `PATH` 环境变量，还会自动注册图片文件关联并无缝集成 Windows 11 默认应用，同时支持基于 Windows 注册表的安装路径重装记忆与平滑版本升级。

**开发者：**
```powershell
# 克隆项目
git clone https://github.com/MikeWu-GM/PicaView.git
cd PicaView

# 运行开发版本
cargo run --release -- "C:\path\to\your\image.jpg"
```

## 📦 安装与构建

### 1. 前置要求
*   **Rust**: 1.77.2+ (推荐 1.93.0+)
*   **C 编译器**: Linux 下需要 `build-essential`，Windows 下需要 MSVC。

### 2. 生产环境构建
**Linux (标准可执行文件):**
```bash
cargo build --release
```
构建产物将存放在 `target/release/` 目录下。

**Windows (MSI 安装包):**
```powershell
$env:PATH += ";$PWD\wix-bin"
cargo wix --nocapture
```
MSI 安装包将生成在 `target/wix/` 目录下。此外，你也可以在 Windows 下直接双击或运行交互式控制台脚本 `.\scripts\build.bat`，选择构建 MSI 安装包或生成绿色免安装的便携版 ZIP 压缩包。

## 🛠️ 核心功能

*   **GPU 硬件加速**: 基于 WGPU 28 实现硬件级渲染，提升图像显示的平滑度。
*   **大图平铺支持**: 引入 VRAM Streaming 显存直写逻辑，在浏览高分辨率图像时，后台进行切片加载，保持基础的拖拽响应速度，降低内存占用。
*   **原生执行**: 基于 Rust 原生编译，提供基础的快速启动能力。
*   **常规格式支持**: 支持加载 WebP, TIFF, JPEG, PNG, BMP, GIF, ICO 格式。
*   **目录扫描机制**: 提供“渐进式滑动窗口扫描”和“持久化快照缓存”机制，在包含大量图片文件的目录下，能够维持正常的导航功能而不易卡死。
*   **后台预加载**: 连续翻页时支持低优先级预加载下一目录内容，改善跨文件夹浏览的连贯性。
*   **漫画模式**: 支持级联导航与跨目录连续阅读。
*   **归档包读取 (ZIP/CBZ/7Z/RAR)**: 允许在不主动解压的情况下预览压缩包内的图片。其中 ZIP/CBZ 由 Rust 库处理，RAR/7Z 依赖系统中已安装的相应命令行工具。支持带密码包的基本解密弹窗，提供画廊缩略图解析等功能。
*   **长图模式**: 支持纵向排版的图片拼合与鼠标滚轮垂直平移。内建基本的自动滚动模式，适用于长篇漫画或长截图阅读。
*   **滚轮行为**: 支持通过鼠标左键单击或设置来切换滚轮行为（在缩放与切换图片之间），包含基本的防抖过滤。
*   **壁纸设置**: 支持一键设置为系统壁纸（兼容 Windows 及 GNOME 等）。
*   **常规文件操作**: 提供右键复制文件、另存为及调用系统关联软件打开的功能。
*   **右键菜单**: 可生成并应用系统的右键菜单关联脚本（Windows .reg / Linux .desktop）。
*   **进程限制**: 默认采用单实例以控制系统资源占用，支持多实例模式，且内置最大 5 实例的硬上限防线。
*   **状态记录**: 本地记录各个文件夹的最后浏览位置和选中状态。
*   **快捷评分**: 支持 1-5 键快捷评分图片并进行本地目录归档。
*   **EXIF 信息查询**: 支持以半透明悬浮面板查看基础相机元数据，以及按参数过滤当前目录资产的功能。
*   **视口锁定**: 在对比同尺寸图片时，可锁定当前缩放比例与中心坐标进行直接切换。
*   **单通道模式**: 支持单独检视 R/G/B/A 色彩通道。
*   **多图对比**: 提供双视口平铺设计，支持左右分屏、上下分屏及卷帘交叠模式，进行基础的并排对比。
*   **ICC 色彩管理**: 借助 lcms2 解析并校正图像的 ICC 文件至 sRGB 空间，减缓在广色域显示器下的偏色情况。
*   **无边框拖拽**: 支持 `Ctrl + 左键` 拖动无边框窗口，并支持系统层面的文件直接拖入动作。

## 📖 使用指南

### CLI 参数
PicaView 支持通过命令行直接打开图片或目录：
```bash
picaview [路径] [参数]
```
*   **传入文件路径**: 以查看器模式（Viewer Mode）直接打开该图片。
*   **传入目录路径**: 以画廊模式（Gallery Mode）打开该目录进行资产浏览。

### 画廊交互与缩略图居中联动
*   **滚动**: 高性能虚拟滚动，无视目录大小。选中缩略图时会自动联动平移视口，使其自动居中/对齐。
*   **搜索**: 实时文件名过滤。
*   **排序**: 支持按名称、大小、日期进行自然语言排序。

### 快捷键与交互工作流
*   **滚轮行为切换**: 鼠标左键单击主视口（或在设置中触发）可切换滚轮模式。
    *   *缩放模式*: 滚动滚轮将以鼠标当前指针位置为中心进行无级放大/缩小。
    *   *切图模式*: 滚动滚轮即可在前后图片间循环切换（已配备 250ms 节流防抖，防止高频滑动时连续切换多张图）。
*   **长图模式**: 点击“切换长图模式”选项。启用后，滚动滚轮即可直接纵向平移滚动长图（无需按住 `Ctrl` 键）。
    *   `M` / `m`: 一键开启/关闭**自动滚动**模式，进入免提阅读体验。
    *   `向上箭头` / `向下箭头`: 手动微调画面的垂直位置。如果在自动滚动开启时按下，则会动态平滑地加减速。
    *   `PageUp` / `PageDown`: 在一维瀑布流中快速大跨度翻页。
*   **图片评分与归类**:
    *   `1` - `5`: 为当前浏览图片评分。后台异步将文件复制到当前目录下的 `Star_{rating}` 子文件夹内，并显示状态 HUD。
    *   `Ctrl` + `1` - `5`: 快速切换画廊视图至对应的 `Star_{rating}` 评分目录（如果目录存在）。
    *   `Ctrl` + `0`: 从评分目录返回跳转前的原始目录。
    *   `Ctrl` + `鼠标左键`: 拖拽窗口的任意区域以移动窗口位置（适用于无边框窗口化模式）。在无图的空白背景下，直接使用鼠标左键即可拖曳移动窗口。
    *   **文件拖放**: 直接从 Windows 资源管理器将图片文件拖曳并丢入无边框窗口内，即可瞬间载入并打开（即使在 Administrator 提权模式下运行也完美支持）。
*   **色彩通道与对比模式快捷键**:
    *   `R` / `G` / `B` / `A`: 切换 GPU 渲染输出至对应的红、绿、蓝、透明度单通道模式。
    *   `C`: 若已处于单通道模式，则恢复默认 RGB；若处于 RGB 正常模式，则一键开启/关闭**双图联动同步对比模式**（自动载入下一张图并在左右视口呈现同步平移与缩放）。
    *   `V`: 一键开启/关闭**视口与缩放物理锁定 (Viewport Lock)**。
    *   `I`: 一键显示/隐藏**磨砂玻璃 EXIF 数据面板**。
    *   *自选对比图片*：直接在底部缩略图画廊或平铺网格大画廊中，**鼠标右键点击**任意一张图片，即可瞬间将其作为对比视口的加载目标。
    *   *切换对比方向*：开启对比后，在主视口**鼠标右键**并点击即可在**左右分屏**、**上下分屏**和**卷帘对比 (Swipe)** 三种模式间循环切换。在卷帘模式下，可直接拖拽中央滑块进行像素级比对。
*   **EXIF 过滤侧滑面板**: 在右键上下文菜单（ContextMenu）中开启，可在侧边栏灵活筛选符合相机光学属性的资产子集。

## ⚙️ 高级配置

### 系统集成
您可以导出并应用系统右键菜单脚本，使 PicaView 成为默认打开方式：
1.  在应用内点击“导出集成脚本”。
2.  **Windows**: 运行导出的 `.reg` 文件。
3.  **Linux**: 将 `.desktop` 文件放置于 `~/.local/share/applications/`。

### 日志系统与诊断信息
PicaView 内置了异步非阻塞式日志记录系统，用于故障排查：
*   **日志位置**：当在无命令行控制台的发布版模式下运行（`windows_subsystem = "windows"`）时，日志将被自动重定向输出至本地磁盘物理文件中（例如 Windows 平台为 `AppData/Local/PicaView/logs/` 目录）。
*   **日志清理**：日志系统内置滚动拆分及自动清理机制，将自动修剪删除超过 7 天的旧日志文件，保障磁盘空间水位。
*   **性能隔离**：物理计算、瓦片分配等高频循环的 `DEBUG`/`TRACE` 日志在发布版中已被默认屏蔽过滤，避免产生 I/O 性能瓶颈。

### 杀毒软件误报申诉与白名单指引
由于 PicaView 采用了 Win32 窗口子类化钩子（`SetWindowSubclass` 以支持无边框拖放），可能会在严格的 Windows Defender 或第三方安全软件中触发误报拦截。（注：以往用于硬件按键检测的 `GetAsyncKeyState` API 现已被严格剥离清洗，彻底排除了键盘记录器木马的启发式误报可能）。
*   **本地排除**：您可以安全地将 PicaView 的开发或安装目录添加至您的安全软件“排除项（白名单）”中。
*   **申诉说明**：关于如何向微软 Windows Defender、360 安全卫士及腾讯电脑管家官方提交免杀误报申诉的具体操作流程，请参阅详尽的：[.documents/2026_07_19_00_49_42_false_positive_submission_guide.md](.documents/2026_07_19_00_49_42_false_positive_submission_guide.md)。

### 资产安全与缓存说明
PicaView 完全运行在本地，**不会上传**任何您的图片数据。
*   **缩略图缓存**: 存储在系统默认的 App Cache 目录中，可随时在应用设置中清除。
*   **位置记录缓存**: 文件夹最后浏览位置存储在应用配置目录下的 `folder_positions.json` 本地文件中，无任何外部遥测或网络连接。
